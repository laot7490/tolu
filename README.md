# TOLU

[![npm version](https://img.shields.io/npm/v/@laot/tolu?style=flat&colorA=18181B&colorB=28CF8D&logo=npm)](https://www.npmjs.com/package/@laot/tolu)
[![GitHub License](https://img.shields.io/github/license/laot7490/tolu?style=flat&colorA=18181B&colorB=white)](https://github.com/laot7490/tolu/blob/main/LICENSE)

Convert TypeScript types and interfaces to EmmyLua annotations.

Useful when a Vite/NUI frontend shares shapes with Lua (FiveM, etc.).

## Install

```bash
npm i -D @laot/tolu
```

Or run via npx:

```bash
npx @laot/tolu build src/types/index.ts -o ../types/generated.lua
```

## Vite

```ts
import { defineConfig } from 'vite'
import tolu from '@laot/tolu/vite'

export default defineConfig({
  plugins: [
    tolu({
      input: 'src/types/**/*.ts',
      output: '../types/generated.lua',
    }),
  ],
})
```

Runs on `buildStart` and regenerates when matching type files change in dev.

## CLI

```bash
tolu build src/types/index.ts -o ../types/generated.lua
tolu build "src/types/**/*.ts" -o ../types/generated.lua
tolu build "src/types/**/*.ts" -o ../types/generated.lua -w
```

`generate` is an alias for `build`. Use `-w` to watch inputs and regenerate on change.

## Output

Generated files start with:

```lua
-- This file is auto-generated by TOLU. Do not edit manually.
-- https://github.com/laot7490/tolu
```

Example:

```ts
export type User = {
  id: number
  name: string
  online?: boolean
}
```

```lua
---@class User
---@field id number
---@field name string
---@field online boolean|nil
```
